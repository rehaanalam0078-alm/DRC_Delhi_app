## 📖 About the Project

**DRC Delhi** is an Android application developed for the **Digital Resources & Training Centre (DRC), New Delhi**.

The application provides a convenient mobile interface for accessing the DRC Delhi learning and professional development platform. It connects learners with online courses, workshops, webinars, study resources, test series, events, notifications, and other Library & Information Science (LIS) learning opportunities.

The application is designed to make the DRC Delhi platform easily accessible from Android smartphones.

🌐 **Official Website:** https://drcdelhi.in/

## 🏗️ Technology Stack

The application is built using modern Android development technologies.

| Technology | Usage |
|---|---|
| **Kotlin** | Primary programming language |
| **Android SDK** | Android application development |
| **Android Studio** | Development environment |
| **WebView** | DRC Delhi website integration |
| **Jetpack** | Android components |
| **AndroidX** | Modern Android libraries |
| **Material Design** | UI and application styling |
| **View Binding** | Type-safe view access |
| **Android SplashScreen API** | Application launch experience |
| **HTTPS** | Secure website communication |
